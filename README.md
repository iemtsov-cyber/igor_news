# Новости Игоря

Персональная накопительная лента: технологии, ИИ, космос, экономика, инженерия, шахматы; мир с вниманием к России, на русском. Редполитика: `editorial_policy.md` (уточнена 02.11.2026).

- Каждые четыре часа (03:17, 07:17, 11:17, 15:17, 19:17, 23:17 МСК): до 15 качественных новых материалов, а не обязательная квота. GitHub может задерживать cron.
- Один подтверждённый актуальный мем в день, если найден. Без выдуманного мема ради нормы.
- Только бесплатный `openrouter/free` или явный `:free`; платные fallback запрещены кодом. Бесплатный сервис может быть ограничен или недоступен.
- При отказе редактора не публикуется сырой RSS. История остаётся на месте, дата контента не меняется. `docs/health.json` отдельно хранит время проверки, статус и количество добавленных материалов.
- RSS-заголовок — ограниченное свидетельство, не полная статья. Редактор не должен достраивать подробности; автоматические проверки URL/дат/цифр не заменяют полноценный фактчекинг.
- Новые материалы сохраняют ссылки, названия и реальные даты источников. Старым материалам недостающие источники не выдумываются. Дубли проверяются по URL, ID и заголовку.
- История, стабильные ID и browser-local лайки сохранены; между устройствами оценки не синхронизируются.

## Запуск и тесты

Рабочая точка входа: `python news_v81.py`. Используется существующий GitHub Actions secret `OPENROUTER_API_KEY`; не помещайте ключ в код или файлы. Новый платный сервис не нужен.

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m py_compile news.py news_v8.py news_v81.py
```

Тесты офлайн, API не вызывают. Полный запуск собирает RSS, при наличии ключа вызывает только бесплатную модель и обновляет локальные `docs/`/`state.json`. В GitHub Actions job ограничен 15 минутами. Изменения кода в main запускают проверку/публикацию, обновление только контента не запускает рекурсивный workflow.

## Диагностика

GitHub Actions success означает успешную сборку/доставку. Проверяйте также `health.json`: `success`, `no_new_items` или `degraded`. При `degraded` не обещаем новый выпуск; последний контент и архивы сохранены. OpenRouter-ошибки выводятся безопасными кодами без ответов/ключей. Если бесплатный провайдер стабильно не работает, требуется отдельное решение о замене бесплатного пути, а не платный fallback.
