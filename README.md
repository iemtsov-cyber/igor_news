# Новости Игоря — v6

Персональная накопительная новостная лента: сбор свежих материалов → редакционный отбор → добавление новых сюжетов → GitHub Pages.

## Что нового в v6

- GitHub Actions запускается каждые 4 часа.
- Новые сюжеты добавляются в общую ленту и больше не заменяют старые.
- Лента сохраняется в `docs/feed.json`; дневные срезы — в `docs/data/YYYY-MM-DD.json` и `docs/archive/`.
- В каждом обычном обновлении добавляется один случайный сюжет из общего топа без белого списка доменов.
- В ленте появились кнопки `👍 Больше такого` и `👎 Меньше такого`.
- Каждый сюжет получает смысловые теги. Оценки меняют веса категорий/тегов в браузере; будущие новые сюжеты с устойчиво отрицательным профилем могут быть скрыты автоматически.
- Уже прочитанные сюжеты после оценки не исчезают.
- Минимум один мем / хороший Reddit-комментарий / интернет-феномен сохраняется как редакционное требование на день.

## Важное про лайки

GitHub Pages — статический сайт. Поэтому оценки хранятся в `localStorage` браузера и не отправляются на GitHub или OpenAI. Персонализация работает на том устройстве/в том браузере, где вы ставите оценки: новый материал получает категорию и 2–6 тегов, а страница решает, показать его или скрыть по накопленному профилю.

Это безопасно и не требует отдельного сервера. Если позже понадобится синхронизация лайков между телефонами/компьютерами и влияние на сам серверный редактор до генерации, потребуется маленькое внешнее хранилище/API.

## Расписание

`.github/workflows/daily-news.yml` использует:

```yaml
cron: "0 */4 * * *"
```

В Москве это примерно 03:00, 07:00, 11:00, 15:00, 19:00 и 23:00.

Ручной запуск остаётся: GitHub → Actions → `News every 4 hours + GitHub Pages` → `Run workflow`.

## OpenAI secret

В репозитории должен быть GitHub Actions secret:

`OPENAI_API_KEY`

Ключ не должен лежать в коде, `.env` или HTML.

## Публичные данные

`docs/feed.json` и дневные JSON содержат только текст сюжетов, категории, теги персонализации и технические ID. URL и внутренний список источников туда не попадают.

## Локальная проверка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python news.py --dry-run
python news.py
```

## Rate limits

Сборщик сохраняет pacing между крупными API-вызовами и exponential backoff на HTTP 429. Неполный Structured Output повторяется с меньшим числом кандидатов; один проблемный тематический проход не валит весь выпуск.
